Computer Fundamentals

Input,Output and Storage Devices

Input Devices

  1. Keyboard : A Keyboard is a input device that is used to enter text,numbers,symbols, and commands into a computer.It contains different keys such as alphabet keys,numeric keys,function keys,and special keys.
  2. Mouse : A mouse is a pointing input device used to move the pointer,select items,open files and interact with objects on the computer screen.It usually has buttons and a scroll wheel.
  3. Scanner : It is an input device that is used to convert pysical documents,photographs,or images into digital form so that they can be stored and proccessed by a computer.

Output Devices

  1. Printer : A printer is an output device that produces a hard copy of digital information on paper.Printers are commonly used to print documents,photographs and reports.
  2. Monitor : It is an output device that displays text,images,videos, and other visual information generated by the computer.
  3. Speaker : They produces sound from a computer.They are used for listening music,videos, notifications,and other audio.

Storage Devices

  1. Optical Disk : It is a storage device that uses laser technology to read and write data. CDs,DVDs, and Blu-ray discs are examples of optical disks.They are commonly used to store music,videos,software and other files.
  2. USB Flash Drive(Pen Drive) : It is a small,portable storage device that uses flash memory.It can be connected to a computer through a USB port and is commonly used to transfer and store files.
  3. Hard Disk Drive(HDD) : It is a storage device that uses magnetic disks to store data.It is commonly used in computers for storing operating systems,applications,documents,videos and other files.
